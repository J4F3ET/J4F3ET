## Procesador Distribuido de Imágenes

[![Repositorio](https://img.shields.io/badge/Repositorio-%23090b11?style=for-the-badge&logo=github&logoColor=white&labelColor=%23090b11)](https://github.com/J4F3ET/ME.RoadmapProcesadorImagenes)

**Procesador Distribuido de Imágenes**

Construcción de arquitectura modular (Clean Architecture) orientada a eventos con Kafka para la orquestación eficiente y asíncrona de procesos pesados.

**Retos y Logros**

* **Arquitectura modular**: Implementé Clean Architecture para separar responsabilidades y facilitar el mantenimiento del código.

* **Orquestación asíncrona**: Integré Apache Kafka para la comunicación asíncrona entre componentes, mejorando la escalabilidad del sistema.

* **Persistencia distribuida**: Combiné PostgreSQL y Azure Blob Storage para el almacenamiento eficiente de datos estructurados e imagen.

* **Procesamiento de eventos**: Diseñé un sistema orientado a eventos para el procesamiento distribuido de imágenes de alta resolución.
