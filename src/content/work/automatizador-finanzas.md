## Automatizador de Finanzas Personales (ETL)

**Automatizador de Finanzas Personales – RPA & AI**

Orquestación de flujos ETL (Extracción, Transformación y Carga) automatizados utilizando N8N para recolectar datos desde APIs como Gmail y Notion.

**Retos y Logros**

* **Orquestación ETL**: Implementé flujos automatizados con N8N para la extracción y transformación de datos financieros desde múltiples fuentes.

* **Procesamiento inteligente**: Integré modelos de OCR con Python para el reconocimiento automático de documentos fotográficos y facturas.

* **Automatización de procesos**: Diseñé flujos de trabajo que eliminan la carga manual de clasificación y registro de gastos.

* **Integración de APIs**: Conecté múltiples servicios (Gmail, Notion) para la recolección centralizada de datos financieros personales.
